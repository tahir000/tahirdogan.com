# tahirdogan.com

Tahir Doğan'ın kişisel web sitesi. Düz HTML, CSS ve JavaScript; GitHub Pages `main` dalının kökünden yayınlıyor (`CNAME`: tahirdogan.com).

- 23 Kasım 2026'ya kadar site ChatGPT'nin site barındırmasındaydı; bu depo o sitenin birebir kopyasıyla başladı
- Sayfalar: `anasayfa/`, `hakkimda/`, `projelerim/`, `horomania/`, `iletisim/`; kökteki `index.html` 3B giriş sahnesi
- Horomania saat arşivi: kayıtlar `horomania/data.js` içinde (`window.WATCHES`), her kaydın detay sayfası `horomania/saat/<id>/index.html` (aynı kabuk sayfa, başlık ve adres değişir), görseller `horomania/assets/`
- Yeni arşiv kaydında: `data.js` başına kaydı ekle, detay sayfasını kopyala, `sitemap.xml`'e adres ekle, sayfalardaki `data.js?v=` değerini artır
